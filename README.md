# Koru Web

An interactive 3D portfolio built with Three.js.

This project is a personal portfolio website designed as a small
interactive 3D world. Projects, characters and environments can be
explored directly through the scene.

## Built with

- Three.js
- JavaScript
- HTML
- CSS
- Blender
